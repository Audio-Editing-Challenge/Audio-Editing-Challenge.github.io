# Audio Editing Challenge

This repository contains the draft website for the Audio Editing Challenge at the ICASSP 2027 Signal Processing Grand Challenge. The site is built using Jekyll and retains the structure and styling of the Audio Reasoning Challenge website template.

Template source: <https://github.com/Audio-Reasoning-Challenge/Audio-Reasoning-Challenge.github.io>
Template snapshot: `1a8517ed536f`

Content is limited to information supported by the current challenge proposal. Items awaiting confirmation are intentionally left blank on the rendered site.
